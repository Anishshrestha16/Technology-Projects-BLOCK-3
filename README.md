# Technology Projects - BLOCK 3

This repository contains educational materials for **Technology Projects BLOCK 3**, focusing on cybersecurity and system administration concepts. The content is designed as hands-on labs and assignments for students to explore practical aspects of system security, network fundamentals, and information security principles.

## Repository Structure

### 3.1_cyber/
This block covers fundamental cybersecurity topics through practical exercises:

- **01_system-security.md**: Exploring system users, running processes, and open network ports
- **02_file-permissions.md**: Understanding file permissions and access control
- **03_password-security.md**: Password management and security best practices
- **04_phishing-analysis.md**: Analyzing phishing attempts and email security

### 3.2_systems/
This block focuses on system administration and information security principles:

- **01_cia_triad.md**: Hands-on exploration of Confidentiality, Integrity, and Availability (CIA) triad
- **02_firewall.md**: Firewall configuration and network security
- **03_network-traffic.md**: Analyzing network traffic and monitoring
- **04_logins.md**: Authentication systems and login security

## Learning Objectives

By completing these labs, you will:
- Understand core cybersecurity principles
- Learn practical system administration skills
- Gain experience with security tools and commands
- Develop critical thinking about information security
